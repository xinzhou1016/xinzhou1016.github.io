# Xin (Stella) Zhou — Personal Website

Static academic website hosted on GitHub Pages at https://xinzhou1016.github.io/.

- `index.html`: biography, affiliations, and CV link.
- `research.html`: current papers, abstracts, and work in progress.
- `teaching.html`: teaching assistant experience and teaching interests.
- `cv/Xin_Zhou_CV.pdf`: current CV, updated 26 October 2026.

To preview locally, run `python3 -m http.server 8000` from this directory.
